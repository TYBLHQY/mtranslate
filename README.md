## 自定义配置

基本配置：

- 主题切换：catppuccin 系列
- 字体更改：修改界面字体
- 窗口大小：开启/关闭 翻译窗口的大小
- 窗口切换：窗口开启但未聚焦时 先聚焦/直接隐藏
- 静默启动：开启/关闭 启动但不显示窗口
- 发音模式：点击发音/鼠标悬停发音
- 自动翻译：开启/关闭 输入后自动翻译
- 翻译延迟：设置自动翻译的延迟

全局快捷键：

- 打关窗口：切换翻译窗口的显示/隐藏
- 划词翻译：在任何界面划词后按下快捷键即可翻译（终端除外）

代理模式：

- 系统代理
- 直连
- 手动代理
- PAC 脚本
- 自动检测
